# Code of Conduct

We want this project to be useful, welcoming, and technically serious.

Contributors should:
- communicate respectfully
- critique code and ideas rather than people
- assume good intent while remaining clear about technical problems
- avoid harassment, discrimination, threats, or personal attacks
- respect privacy
- avoid spam and low-effort generated contributions

Maintainers may remove content or participation that meaningfully harms the project or community.

For conduct concerns, use the private contact method listed by the repository owner once one is configured.
