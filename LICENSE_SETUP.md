# License setup

Before the public development repository is announced, add the standard Apache License 2.0 text as the root `LICENSE` file.

The easiest safe path is GitHub:
1. Open the repository.
2. Add file.
3. Choose "Create new file".
4. Name it `LICENSE`.
5. Choose a license template.
6. Select **Apache License 2.0**.
7. Commit it.

Do not invent or shorten legal license text.
